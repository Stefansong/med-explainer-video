# 人物、场景与道具（画风由用户定）

人物、场景、道具图标用平台的生图工具出静帧；解剖和示意图不用生图（见 anatomy.md）。动画由代码驱动：立绘可以弹出、移动、缩放、交叉淡化换姿势，人物不会开口说话，表演靠姿势、表情和镜头。

## 0. 先定画风（S3 第一件事）

全片只用**一种**画风，写进 storyboard 的 `style.art`（一段话）。之后每一张图（定妆图、场景、立绘、图标）的提示词都以这段话开头，并带上定妆图当参考。

先问用户想要什么样子；用户没想法就给两三个方向各出一张人物样张让用户挑。可以直接用的写法：

| 画风 | `style.art` 写法 |
|---|---|
| 黏土定格（样例用的） | 黏土定格动画风格的人偶：手工软陶质感，哑光表面，有细微指纹和捏痕，造型圆润简化，头身比约 1:3，五官简洁，柔和的摄影棚布光 |
| 毛毡布偶 | 羊毛毡手工布偶风格：毛绒的毡化纤维质感，缝线细节，造型圆润，头身比约 1:3，纽扣一样的眼睛，柔和的漫射光 |
| 纸艺立体 | 立体纸艺风格：彩色卡纸剪裁、折叠、分层粘贴，边缘有纸的厚度和淡淡的投影，造型几何化，明亮的顶光 |

选画风时注意：要是立体、有体积感的形象（和代码画的扁平示意图能分出层次）；不要写实真人（容易像某个真实的人，也容易显得吓人）；不要指定某个动画公司或某部作品的名字。

## 1. 角色定妆图（每个角色一张，S3 定稿）

提示词要点（中文写给生图工具即可）：

```
<style.art 那段画风描述>。角色定妆图：<年龄、性别、身材、发型、脸部特征、性格>，穿 <上衣、裤子、鞋，颜色写具体>。
全身，头顶到鞋底完整入画，正面或 3/4 侧，自然站姿，双手自然下垂。
纯浅灰色纯色背景，不要场景、不要地面、不要阴影。画面里不要任何文字、水印、logo。竖版。
```

- 每个角色出 2–3 张候选，用户选定一张，存 `assets/lib/characters/<who>/<who>_v1_c<n>.png`（`c<n>` 是候选号），在 storyboard `characters[who].art3d` 登记，再在 `assets/lib/characters/APPROVED.md` 记一行（哪张、哪天、用户原话）。
- 衣服、配饰、**鞋**都在这张图里定死。之后每张姿势图都把定妆图当参考图一起给生图工具，否则衣服颜色、鞋会跨镜头漂移。
- 拟人的器官或病灶角色（结石、细菌）也按同一画风做定妆，但它在解剖图里的位置和形态由代码画，生成的形象只出现在放大圈或特写里。

## 2. 场景定妆图（每个反复出现的地点一张）

```
<style.art 那段画风描述>，同一种画风的室内布景：<地点、陈设、布局（什么在左什么在右）、光线、时间>。
空场景，没有人物；竖版 9:16；平视机位，和人物镜头同一高度。画面里不要任何文字、水印。
```

用户选定后存 `assets/lib/scenes/<地点>/<地点>_v1_c<n>.png`，登记 `places[<地点>].art`；每场用 `scenes[].place` 引用。出某场的姿势图时，把场景图和角色定妆图一起当参考，并在提示词末尾写“房间、布局、光线与参考场景图完全一致”。

## 3. 姿势图 / 立绘（每个镜头需要的动作）

```
参考图 1 是角色定妆图，长相、发型、衣服、鞋必须完全一致，画风也和它完全一致（<style.art 那段画风描述>）。
<角色>正在<动作、表情>，全身，<朝向>。
纯品红色 #FF00FF 纯色背景，不要地面、不要阴影、不要场景。画面里不要任何文字、水印。
```

- **背景用纯品红 #FF00FF**（主体本身偏粉、偏紫时改用纯绿 #00FF00）。不要渐变、不要地面阴影，否则抠不干净。
- **立绘里只有人物和他手里拿的东西**。不要桌子、柜子、床这类家具：它们会被当成主体一起留下，压在人物身上，也没法和别的东西分层摆放。坐姿可以带一把简单的椅子；桌子和桌上的东西另出图标（`ic_*`）或用代码道具（`PR.*`）画，在场景代码里摆到人物前面。提示词里写明“只有人物，没有桌子和其他家具”。
- 抠底并登记：在专题目录下
  ```
  python "$SKILL/scripts/tools/cutout.py" <图片路径> sp_<角色>_<动作>
  ```
  产物 `assets/lib/characters/sprites/<id>.png`（透明底、裁到主体），自动写进 `storyboard.assets`。看一眼棋盘格预览 `render/cutout/<id>_check.png`：边缘干净、没有残留底色、空洞（手臂和身体之间）抠掉了。工具提示“左右边 / 底边还有不透明”（左右边缘 2% 的宽度里不透明像素超过 5%，或底边超过 50%：多半是渐变底、地面、阴影没抠掉，或主体顶到了画面边）就按提示重出。
- 场景代码里画：`SP(c, A, 'sp_lz_shock', spX(A, 'sp_lz_shock', 540, 420), 1120, 420, { pop: … })`（参数：中心 x、脚底 y、高度）。换姿势用 `SH.xf` 交叉淡化两张立绘。立绘右缘不超过 900（`spX` 自动收进安全线）。
- 满幅镜头（人物占满整个舞台的特写）：出 9:16 的完整画面（带场景），作为 `assets` 里的普通图片，在场景代码里铺满舞台画；画面要铺满，不留边框，人物头顶不压到顶部章节名。

## 4. 道具图标

```
<style.art 那段画风描述>的道具图标：<物品>，单个物体，居中，柔和光照。
纯品红色 #FF00FF 纯色背景，不要阴影。不要任何文字、标签、logo（药盒、化验单上也不要字）。
```

抠底：`python "$SKILL/scripts/tools/cutout.py" <图片> ic_<物品>` → `assets/lib/props/ic_<物品>.png`；场景代码 `IC(c, A, 'ic_<物品>', x, y, 尺寸)`。需要精确表达程度、颜色的示意（试纸色带、尿色对照、泡沫多少）仍由代码画。

## 5. 检查

- 长相、衣服、鞋跨镜头一致；同一场景的房间布局一致。
- 画面里零文字（生图常在手机屏、药盒、海报上加字，有字就重出）。
- 不画敏感部位；病人形象不丑化。
- 片尾 `outro.ai_note` 写明“角色形象与道具图标由 AI 生成”。
- 定稿图永不覆盖：要改就出 `_v2`，旧的留着。同一个 id 再抠一次不会覆盖；如果图在、但 storyboard 里的登记丢了（比如整份重写过 storyboard），再跑一次 `cutout.py <图片> <id>` 会补登记。重写 storyboard 时记得保留 `assets`、`characters[].art3d`、`places`。
