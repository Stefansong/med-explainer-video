# 3D 卡通人物、场景与道具

人物、场景、道具图标用平台的生图工具出（皮克斯式 3D 卡通静帧）；解剖示意不用生图（见 anatomy.md）。动画由代码驱动：立绘可以弹出、移动、缩放、交叉淡化换姿势，人物不会开口说话，表演靠姿势、表情和镜头。

## 1. 角色定妆图（每个角色一张，S3 定稿）

提示词要点（中文写给生图工具即可）：

```
皮克斯风格 3D 卡通角色定妆图：<年龄、性别、身材、发型、脸部特征、性格>，穿 <上衣、裤子、鞋，颜色写具体>。
全身，头顶到鞋底完整入画，正面或 3/4 侧，自然站姿，双手自然下垂。
纯浅灰色纯色背景，不要场景、不要地面、不要阴影。画面里不要任何文字、水印、logo。竖版。
```

- 每个角色出 2–3 张候选，用户选定一张，存 `assets/lib/characters/<who>/<who>_v1_c<n>.png`（`c<n>` 是候选号），在 storyboard `characters[who].art3d` 登记，再在 `assets/lib/characters/APPROVED.md` 记一行（哪张、哪天、用户原话）。
- 衣服、配饰、**鞋**都在这张图里定死。之后每张姿势图都把定妆图当参考图一起给生图工具，否则衣服颜色、鞋会跨镜头漂移。
- 拟人器官或病灶角色（结石、细菌）也做 3D 定妆，但它在解剖图里的位置和形态由代码画，3D 形象只出现在放大圈或特写里。

## 2. 场景定妆图（每个反复出现的地点一张）

```
皮克斯风格 3D 卡通室内场景：<地点、陈设、布局（什么在左什么在右）、光线、时间>。
空场景，没有人物；竖版 9:16；平视机位，和人物镜头同一高度。画面里不要任何文字、水印。
```

用户选定后存 `assets/lib/scenes/<地点>/<地点>_v1_c<n>.png`，登记 `places[<地点>].art`；每场用 `scenes[].place` 引用。出某场的姿势图时，把场景图和角色定妆图一起当参考，并在提示词末尾写“房间、布局、光线与参考场景图完全一致”。

## 3. 姿势图 / 立绘（每个镜头需要的动作）

```
参考图 1 是角色定妆图，长相、发型、衣服、鞋必须完全一致。
<角色>正在<动作、表情>，全身，<朝向>。
纯品红色 #FF00FF 纯色背景，不要地面、不要阴影、不要场景。画面里不要任何文字、水印。
```

- **背景用纯品红 #FF00FF**（主体本身偏粉、偏紫时改用纯绿 #00FF00）。不要渐变、不要地面阴影，否则抠不干净。
- 抠底并登记：在专题目录下
  ```
  python "$SKILL/scripts/tools/cutout.py" <图片路径> sp_<角色>_<动作>
  ```
  产物 `assets/lib/characters/sprites/<id>.png`（透明底、裁到主体），自动写进 `storyboard.assets`。看一眼棋盘格预览 `render/cutout/<id>_check.png`：边缘干净、没有残留底色、空洞（手臂和身体之间）抠掉了。工具提示“左右边 / 底边还有不透明”就按提示重出。
- 场景代码里画：`SP(c, A, 'sp_lz_shock', spX(A, 'sp_lz_shock', 540, 420), 1120, 420, { pop: … })`（参数：中心 x、脚底 y、高度）。换姿势用 `SH.xf` 交叉淡化两张立绘。立绘右缘不超过 900（`spX` 自动收进安全线）。
- 满幅镜头（人物占满整个舞台的特写）：出 9:16 的完整画面（带场景），作为 `assets` 里的普通图片，在场景代码里铺满舞台画；画面要铺满，不留边框，人物头顶不压到顶部章节名。

## 4. 道具图标

```
3D 卡通风格图标：<物品>，单个物体，居中，柔和光照。
纯品红色 #FF00FF 纯色背景，不要阴影。不要任何文字、标签、logo（药盒、化验单上也不要字）。
```

抠底：`python "$SKILL/scripts/tools/cutout.py" <图片> ic_<物品>` → `assets/lib/props/ic_<物品>.png`；场景代码 `IC(c, A, 'ic_<物品>', x, y, 尺寸)`。需要精确表达程度、颜色的示意（试纸色带、尿色对照、泡沫多少）仍由代码画。

## 5. 检查

- 长相、衣服、鞋跨镜头一致；同一场景的房间布局一致。
- 画面里零文字（生图常在手机屏、药盒、海报上加字，有字就重出）。
- 不画敏感部位；病人形象不丑化。
- 片尾 `outro.ai_note` 写明“角色形象与道具图标由 AI 生成”。
- 定稿图永不覆盖：要改就出 `_v2`，旧的留着。
