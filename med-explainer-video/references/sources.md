# 医学来源：按选题检索，不预设专科

这个技能不绑定任何专科或指南。每个选题都要**现查**权威来源，口径表（`claims[]`）里的每一条都要能指回来源原句。你（AI）记忆里的医学知识只能用来提问和找方向，不能当出处。

## 1. 先问用户

- 选题、目标观众（患者 / 家属 / 大众；年龄层）、发布地区（来源优先用当地的）。
- 用户手头有没有要依据的资料（科室宣教材料、指南 PDF、教材章节）：有就以用户给的为主，放进 `design/source/`，同样登记进 `sources`。
- 用户的身份：是不是相关专业的医务人员。不是的话，提醒成片发布前请专业人员审口径。

## 2. 检索（用联网搜索工具；没有联网能力就明确告诉用户，请用户提供资料）

按下面的优先级找，同一问题至少两个独立来源互相印证：

1. **国家或地区的诊疗指南、规范、专家共识**：卫生主管部门发布的诊疗规范，各专科学会的指南与共识（按选题对应的学会查，不要套用别的专科的）。
2. **国际权威机构**：世界卫生组织，以及选题所在领域公认的国际学会指南。
3. **权威教材与工具书**：现行版本的规划教材、药典、说明书（涉及药物时）。
4. **面向公众的官方科普**：卫生主管部门、疾控机构、大型公立医院官网、权威医学会的患者教育页面。这类最适合做科普的措辞参考。
5. 高质量综述、系统评价：只在上面没有覆盖时补充，写清证据等级。

不用的来源：自媒体文章、商业机构软文、问答社区、没有署名和日期的网页、过期被替代的旧版指南。

检索时：
- 查**最新版本**，记下发布年份；发现已被更新或撤销就换新的。
- 打开原文读对应段落，不要只看搜索结果摘要。
- 数字、剂量、时间窗、年龄界限、“多数 / 少数”这类限定词，必须逐字对原文。
- 来源之间有分歧：两种说法都记下来，交给用户定，不要自己挑一个。
- 查不到可靠来源的说法：不进片，或在口径表里标“待核”并在 S0 明确提给用户。

## 3. 留意使用条款

有些机构的指南对转载、翻译、输入 AI 工具有限制（例如个别国际学会明确禁止把指南全文输入生成式 AI 或未经许可翻译）。打开来源时看一眼版权和使用条款：
- 有限制的：不要整段复制或上传原文；只引用结论并注明出处，或请用户改用允许使用的同类来源。
- 片尾和简介里按来源要求署名（如 CC BY 素材）。

## 4. 登记

`storyboard.sources`：每个来源一个编号，写清名称、发布机构、版本或年份、网址或书目、检索日期。

`storyboard.claims[]`：`{id, text, src, quote}`
- `text`：片子要采用的口径，照原文意思写，不拔高、不绝对化。
- `src`：来源编号（可多个，如 `"S1, S3"`）。
- `quote`：来源里对应的原句（或页码、章节），让用户能一眼核对。

`red_flags[]`（什么情况要马上就医）同样要有来源，宁全勿缺。

`python $P s0 <专题>` 生成的修订稿里有口径表（含来源原句）和文献列表；没登记来源的口径会被标出来。

## 5. 把关

- S0 是硬停点：把口径表逐条给用户看，**由用户确认**；涉及用药、手术指征、急症处理的条目提醒用户重点看。
- 建议另开一个对话当“独立医学审稿人”：只给它 storyboard，让它逐句逐卡对照来源找走样的地方（数字、限定词、因果说得太满），问题交给用户定。
- 片子只做健康科普：不给个体化诊断和用药建议，结尾不承诺疗效，带免责声明（`disclaimer`）。
